# ghostwire-npc-intelligence
A modular NPC intelligence framework for Cyberpunk‑style games, combining dialogue systems, behavior logic, and AI‑driven interactions. Built for experimentation, modding, and future expansion.
🌐 GHOSTWIRE NPC INTELLIGENCE
A cyberpunk‑themed NPC intelligence framework for dialogue, behavior, and AI experimentation.

Ghostwire NPC Intelligence is a modular toolkit for building smarter NPCs in Cyberpunk‑style games and mods.
It blends Lua, Python, and behavior graph logic to create NPCs that react, respond, adapt, and evolve — designed for modders, scripters, and curious technomancers who want to push NPC behavior beyond static scripts.

This project is built for:

experimentation

learning

modding

future expansion

personal growth in scripting + AI logic

Whether you’re crafting a new NPC system for Cyberpunk 2077, building your own game prototype, or just exploring AI behavior, Ghostwire gives you a neon‑lit foundation to build on.

⚡ Features
Modular NPC behavior system (idle, greet, react, flee, follow, etc.)

Dialogue tree engine with branching logic

Lua + Python hybrid scripting

Behavior graphs for NPC decision‑making

Tools for packaging mods (REDmod‑friendly structure)

Cyberpunk‑themed architecture + naming

Expandable modules for future AI integration
